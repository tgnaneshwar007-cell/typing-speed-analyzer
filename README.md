# ⌨️ Typing Speed Analyzer

A simple Python command-line project that measures typing speed and accuracy.

## Features

* Measures typing time
* Calculates accuracy
* Calculates words per minute (WPM)
* Gives a performance rating

## Tech Used

* Python
* `time` module
* Basic loops and conditions

## How to Run

```bash
python typing_speed_analyzer.py
```

* `time.time()`
* String comparison
* Loops
* Conditional statements
* Basic calculations
* User input

A small project, but a practical way to apply Python fundamentals.
